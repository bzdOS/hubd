# Recipe: categorize — harvest projects and tasks from a dialog

This recipe IS the Harvest Protocol — the current prompt lives in
[../HARVEST.md](../HARVEST.md) (it grew truth-discipline rules and structured
output that this page used to duplicate, badly). Paste it at the END of a
working conversation, or feed it a transcript from anywhere.

One company-specific addition: after harvesting, write one journal entry —
projects touched / tasks added / decisions logged / questions raised — so the
next session sees the harvest happened without diffing the base.
