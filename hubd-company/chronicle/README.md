# chronicle/ — the team's memoir, one chapter a week

Weekly chapters written by an agent from the journal, task events and card
diffs — `recipes/chronicle.md` is the procedure. One file per ISO week
(`2026-W29.md`), **append-only**: corrections are a new "erratum" line, never
a rewrite.

A chapter has four voices: **Chronicle** (what moved, in prose) · **Numbers**
(`scripts/behavior_metrics.mjs`) · **The Critic** (past decisions with dates
vs what the week actually did) · **Questions** (probes sent to the owner,
`recipes/probe.md`).

Why bother: the journal records *what happened*; the chronicle records *what
it meant*. Journals get grepped, chronicles get read — including by you,
years from now, and by every fresh agent session that needs the story so far
in two pages instead of two thousand JSONL lines.

Chapters roll up: ~6 weeks or one strategy shift = an **arc** (a single synthesis
file, e.g. `2026-arc-2_two-tracks.md`); arcs roll up into a year. Write arcs
by hand or by agent — but only from chapters, never from raw logs.
